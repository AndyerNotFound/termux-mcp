Termux MCP 源码提取包 (2026-09-19)
==================================
说明: 让 MCP 客户端通过 HTTP / SSE 远程操作 Termux (执行命令 / 读写文件)。
  * 服务器 = mcp-server (本包主体, 原名 index.js)
  * 客户端 = 极简 MCP 客户端 (零依赖, 支持 stdio + HTTP/SSE)
  * 测试   = bash + curl 冒烟脚本

【内容】
termux-mcp/
  index.js             MCP 服务器 (shell 执行 / 文件操作; SSE 传输)
  srv-debug.js         早期调试版服务器 (留档)
  package.json / package-lock.json   依赖: @modelcontextprotocol/sdk + express + zod
  .llm_mcp.js          极简 MCP 客户端 (原机同名)
  test-mcp-bash.sh     冒烟测试脚本 (bash + curl)
  .mcp_servers.json    客户端服务器配置示例 (API Key 为环境变量占位)

【处理】
- 去注释: js 注释移除 (字符串 / 模板字面量完整保留)
- 脱敏: 全文扫描 0 命中 (BASE 目录 /storage/emulated/0/Download/Termux 为公开路径, 保留)
- index.js 含 2026-09-18「execFile 异步化」修复 (原 spawnSync 会冻结整个进程)

【验证】
- node --check: index.js / srv-debug.js / .llm_mcp.js 3/3 通过
- 运行环境: 手机 Termux 实机运行中 (Node 18+)
  ※ 沙箱未安装其 npm 依赖, 未做本机运行测试; 静态检查全部通过

【运行】
- cd termux-mcp && npm install && node index.js
  (默认监听 127.0.0.1:6218, SSE 入口 /sse; 端口见 index.js 顶部)
- 客户端配置参考 .mcp_servers.json
